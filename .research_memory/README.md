# 研究记忆库（Research Memory）

这个目录是 AI 助手的**长期记忆**，用于跨会话保存硕士开题相关的文献调研、方法判断、决策日志。

## 文件组织

| 文件 | 用途 | 何时更新 |
|---|---|---|
| `00-context.md` | 研究者背景、开题目标、约束、偏好 | 用户表达新的偏好/目标/约束时 |
| `01-directions.md` | 候选研究方向 + 每个方向的可行性判断 | 提出新方向、推翻或确认旧方向时 |
| `02-papers.md` | 论文池：必读/可读/备查 + 引用数 + 已下载状态 | 新增论文、引用数更新、读完一篇后填观点 |
| `03-trends.md` | 2025-2026 方法学趋势观察（汇总性结论） | 引用网络/批量调研后产生新趋势判断时 |
| `04-decisions.md` | 关键决策日志（带日期 + 理由） | 每次做"取舍"、"换方案"、"放弃某方向"时追加 |
| `05-next-steps.md` | 当前待办与下次切入点 | 每轮对话结束时刷新（保留近 3 次） |

## 自动更新规则（AI 自检清单）

每轮对话**临结束前**，AI 必须自问以下问题，命中任一就更新对应文件：

1. 用户表达了新的偏好、约束、目标 → 改 `00-context.md`
2. 讨论了新研究方向 / 推翻了旧判断 → 改 `01-directions.md`
3. 出现了新论文（被推荐/被下载/被读过）/ 拿到了新引用数 → 改 `02-papers.md`
4. 形成了新的"X 是 2026 趋势"类的横向判断 → 改 `03-trends.md`
5. 做了"选 A 不选 B"、"放弃 X"类的决策 → 追加到 `04-decisions.md`
6. 本轮对话结束时有未完成的 next step → 刷新 `05-next-steps.md`

**触发时机**：
- AI 在每轮回复用户**之前**完成更新（用户看到回复时记忆已落盘）
- 不需要用户主动提醒
- 如果本轮纯粹是闲聊或纯解释、没有新结论 → 不更新

## 写作约定

- 所有时间戳使用 `YYYY-MM-DD` 格式
- 论文统一使用格式：`论文简称 (arXiv:xxxx.xxxxx)`
- 引用数标明来源：`[OpenAlex: N]` 或 `[SemanticScholar: N]`
- 决策日志条目格式：
  ```
  ### YYYY-MM-DD：决策标题
  - **背景**：...
  - **选项**：A / B / C
  - **决定**：选 X
  - **理由**：...
  ```

## 为什么这么分

- 不按"会话日期"切，按"研究问题"切——开题写作时按问题查更顺
- `04-decisions.md` 是唯一按时间序的文件，专门追"为什么当初这么选"
- `05-next-steps.md` 单独成文件，因为它高频变化，避免污染其他稳定内容
